Command List

Here's a list of all available commands your server can use.

!ban [user]

Bans a user from the server.

!kick [user]

Kicks a user from the server.

!mute [user]

Mutes a user in all channels.

!warn [user] [reason]

Warns a user and logs the reason.

!help

Displays all available commands and their descriptions.
